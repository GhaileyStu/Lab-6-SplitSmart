# ChatGPT Review Prompt

Review the SplitSmart architecture documents for technical quality and requirement fit.

Use these documents as the source of truth:
- `spec.md`
- `architecture.md`
- `architecture-alternative.md` (if present)
- `UserRequirement.md`

Assess the architecture against the following:
- functional requirements
- non-functional requirements
- business rules and approval workflow
- domain model completeness
- security and privacy
- implementation complexity
- scalability and maintainability
- documentation quality and UML consistency

Provide a detailed but concise review with:
- summary of the project context
- key requirements identified
- architecture strengths
- architecture weaknesses
- gaps and assumptions
- comparison between the baseline and alternative designs
- final recommendation on which architecture is more appropriate

Do not assume the more advanced architecture is automatically better. Prefer the architecture that is most realistic, maintainable, and aligned with SplitSmart's actual requirements and MVP scope.
